# Memory Palace

An interactive, single-page visualization of how an artificial memory system forms, stores, merges and forgets memories.

**Live:** https://memory-map-swart.vercel.app

- Click to create memories and watch them evolve, merge and fade over time
- Four memory types: visual, emotional, linguistic, abstract
- Controls to add memories, toggle decay, clear everything and export the current frame

Built as a single `index.html` with no build step: open it in a browser to run it locally.
